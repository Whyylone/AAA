# Why? Lone — Minimal Artist Website

Responsive static website starter for Why? Lone: music, visuals, live bookings, licensing, press, and collaborations.

## Preview
Extract the ZIP and open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `why-lone`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` directly into the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub to provide the public URL.

## Before publishing
- Replace `hello@yourdomain.com` with the official email.
- Replace the generic Instagram link with Why? Lone's official profile.
- Replace placeholder release links with verified Spotify/Apple Music/YouTube/SoundCloud URLs.
- Add approved artwork, real videos, show dates, and official press details as available.
- Music licensing must be confirmed track by track; do not promise clearance until applicable rights are verified.

The release descriptions and cover designs are starter placeholders, not official artwork or verified release links. Dark cinematic styling, responsive navigation, no framework, and no paid hosting required.
